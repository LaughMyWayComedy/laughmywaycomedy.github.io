Privacy notice

Effective October 30, 2026

This notice explains how the owner-operated LaughMyWay Publisher desktop tool handles Google and YouTube data. The public website is informational; it has no account sign-up or Google sign-in form.

Google access and data collected

When the channel owner authorizes the desktop tool through Google OAuth, LaughMyWay Publisher requests permission to upload YouTube videos and read YouTube channel and video information. If the owner enables video management, it also requests permission to update an existing video’s settings.

The tool checks the authorized channel ID and reads channel information to confirm that it is connected to the intended LaughMyWay channel. It reads the owner’s uploaded video metadata and status, including video ID, title and other snippet details, privacy setting, upload and processing state, and scheduled publish time when applicable. It handles the video files, thumbnails, titles, descriptions, and tags selected for publishing from the owner’s local computer. The tool does not request Gmail access or read email messages.

How data is used

LaughMyWay Publisher uses this access to verify the connected channel, upload selected finished videos and thumbnails, apply the chosen title, description, tags, and visibility, and check or update an existing upload when the owner directs it to. The queue can submit locally prepared videos under the owner’s configured settings.

Google API data is not sold, used for advertising, or used to train AI models. The publishing tool does not use Google data for audience profiling. Our use and transfer of Google API data follows the Google API Services User Data Policy, including its Limited Use requirements.

Local storage and security

OAuth access and refresh tokens, resumable upload session details, and the upload ledger are stored on the owner’s Windows computer under the current user’s local application data. The tool encrypts these records with Windows Data Protection API (DPAPI). The ledger includes the channel ID, video IDs, content hashes, requested and observed visibility, processing state, and other publishing status needed to resume and verify uploads. Selected media files and publishing metadata remain in local project folders.

The tool does not set an automatic expiration for these local records. They remain until the owner removes them. Removing the upload ledger without checking the channel may affect duplicate-upload protection.

When data is shared

When an upload or management action runs, the tool sends the selected video, thumbnail, and related metadata to Google/YouTube using the YouTube Data API, and reads the relevant channel or video response. The visibility selected by the owner determines whether a video is private, unlisted, or public on YouTube. YouTube separately handles uploaded videos under its own terms and privacy practices.

The tool does not share Google API data with advertisers or data brokers.

Your control and deletion

The channel owner can revoke the app’s Google access at Google Account permissions. Revocation stops future authorized API access, but does not automatically erase local files or videos already uploaded. To ask about removal of local publishing records, contact laughmyway.com@gmail.com. Videos already on YouTube are managed separately through YouTube Studio.

This public website

These pages use local image and style files only. They do not include analytics, tracking scripts, advertising tags, or embedded third-party media. The site does not collect information through a form. If you email us, your message is handled through your email provider and ours. This site may be hosted on GitHub Pages, whose hosting systems may process visitor data such as IP addresses and request logs under GitHub’s privacy statement.

Contact and related policies

Questions about this notice or LaughMyWay Publisher can be sent to laughmyway.com@gmail.com. We will update the effective date on this page if the notice changes.

Read the Google Privacy Policy, YouTube Terms of Service, and Google API Services User Data Policy for those services’ rules.
